SolidWorks MCP controls native, editable CAD through the SolidWorks API.
Before modeling, call get_modeling_guide(topic="index") and read the relevant
workflow plus workflow/operating (call order, selection, recovery); the same
library is exposed at solidworks://guides/index.
Clarify missing dimensions that change the design, then plan feature order,
references and verification. Use only currently advertised tool schemas;
general SolidWorks teaching notes do not imply an MCP operation is available.
Bind the intended CAD document before CAD mutations. After geometry changes, refresh
face/edge references and verify the result by geometry and feature state.
For assembly orientation start with list_components(mode="fast", depth=1),
then inspect only necessary branches. Preserve reference projects and obey
the server's path policy. Guide reading needs no SolidWorks connection and
does not execute a workflow. Read detailed workbook material only on request.
For linked dimensions, repeated revisions or interactive parameter editing,
read get_modeling_guide(topic="workflow/parameter-ui"). Read existing values
before asking, clarify driving inputs and offer a task-specific parameter
form. Distinguish draft values from verified CAD values. Enable CAD apply
only when a real host-to-MCP binding and supported update operation exist;
never substitute custom properties for geometric dimension changes.
The local parameter GUI and MCP tools read_parameter_workspace and
write_parameter_workspace share a persistent project register. Register
drafts and queued requests do not mutate CAD. Read the parameter-ui workflow
for the operational contract and check requests at the start of project work.
For adapting an existing project, read workflow/project-copy. Default to copying
all reachable components and related drawings into a new approved folder before
editing. Use the returned verified manifest and root_document; never mistake
Save As of an assembly for an independent project. Existing dimensions can be
edited with set_model_dimension after reading exact names, units, old values and
active configuration. A single occurrence needs a separately copied component
and replace_component; shared-part geometry affects all matching occurrences.
For the engineering workflow package read workflow/engineering-package.
Use import_parameter_workspace to register actual copied CAD dimensions.
GUI queued cad_jobs are executed by process_parameter_workspace_job on the MCP
thread. The browser queues changes; it does not create an independent COM client.
Use apply_parameter_changes for explicit old/new dimension batches, with optional
root assembly rebuild. Batch failure may leave partial changes; no rollback claim.
Showing only the final result is allowed. Verify exact file paths and distinguish
COM activation from confirmed visibility on the user's desktop.
